# Canadian Urban Institute

The Canadian Urban Institute (CUI) is a national organization based in Canada dedicated to building vibrant, equitable, and sustainable cities. This GitHub contains code we use to run our data research team and the Main Street Canada Metrics Dashboards and Reports and any supporting code for research projects undertaken by the Applied Solutions Lab. If you are interested in collaborating with our team, feel free to reach out to [Greg Spencer](mailto:gspencer@canurb.org) for more information!

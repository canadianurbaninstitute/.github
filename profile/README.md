# We are the Canadian Urban Institute

The Canadian Urban Institute (CUI) is a Canadian organization dedicated to building vibrant, equitable, and sustainable cities through research and dialogue. This GitHub contains code we use to run our research data analytics team, the Main Street Canada Metrics Dashboards / Reports and any supporting code for the myriad research projects undertaken by the Institute's Applied Research Team. 

##### If you are interested in collaborating with the Data Analytics team, reach out to [Greg Spencer, Director of Research](mailto:gspencer@canurb.org) at gspencer@canurb.org for more information!
